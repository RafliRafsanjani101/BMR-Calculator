# BMR-Calculator
Kalkulator Basal Metabolic Rate (BMR) memperkirakan tingkat metabolisme basal Anda—jumlah energi yang dikeluarkan saat istirahat di lingkungan dengan suhu netral, dan dalam keadaan pasca-penyerapan (artinya sistem pencernaan tidak aktif, yang membutuhkan sekitar 12 jam puasa).
