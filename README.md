# BMR-Calculator
Kalkulator Basal Metabolic Rate (BMR) memperkirakan tingkat metabolisme basal, jumlah energi yang dikeluarkan saat istirahat di lingkungan dengan suhu netral, dan dalam keadaan pasca-penyerapan
